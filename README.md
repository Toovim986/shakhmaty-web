# Шахматы — веб-сборка (прототип)

Ранняя однопоточная веб-сборка мобильной 3D-игры на Godot 4.7.2 (Compatibility / WebGL 2).
Открыть: страница GitHub Pages этого репозитория. Версия сборки — `version.json`.

Прототип: первый запуск занимает несколько секунд, первые кадры медленнее из-за компиляции шейдеров.
Фанатский некоммерческий прототип; Warhammer 40,000, Space Marines, Necrons и связанные знаки
принадлежат Games Workshop Limited. Репозиторий содержит только собранные файлы игры.
